# GUI 编辑与可视化

## 时间线直接操作

- 点击空白：seek；点击片段：选中并 seek，同时设置循环预览区间。
- 拖动片段主体：整体平移源区间。
- 拖动片段左右边缘：裁剪起止时间，最小片段 0.1s。
- 工具栏：添加片段、删除、在播放头分割、上移/下移、撤销/重做。
- 表格可直接改标签/开始/结束/置信度；非法区间自动回滚。
- 所有编辑只改本地 segment 列表；点击“保存为新版本”才生成 EditIR revision。

## 长视频视图

- 滚轮缩放（锚定鼠标位置），Shift+滚轮或中键拖动平移，工具栏放大/缩小/适配。
- 标尺按可见范围自适应刻度；片段/镜头/质量标记只绘制可见区间。
- 波形：后端按内容寻址缓存 waveform peaks，时间线按可见范围绘制。
- 缩略图轨：从 1fps 帧清单采样 ≤40 张，异步解码并缓存 QPixmap。
- 播放头移出可见范围时自动平移窗口。

## 播放与监听

- 预览支持代理优先加载与成片切换；播放/暂停、停止、进度拖动、逐帧与循环。
- 音量滑杆控制监听音量，静音按钮可快速切换；两者写入 `desktop.json`，
  下次启动恢复。监听音量不改变成片音量。
- 顶部工具栏提供播放/暂停/停止、撤销/重做、保存版本与渲染入口。

## 循环预览与快捷键

| 键 | 行为 |
|---|---|
| Space | 播放/暂停；若不在循环区间内，从片段起点开始 |
| ← / → | 前后 1 帧 |
| Shift + ← / → | 前后 1 秒 |
| Delete | 删除选中片段 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z / Ctrl+Y | 重做 |
| Ctrl+S | 保存为新版本 |

快捷键在 QLineEdit/QTextEdit/表格单元格编辑状态下不拦截输入。

## 面板

顶部收敛为 4 个工作区：
**剪辑**（智能剪辑 / 版本与片段 / 我的偏好）、**素材与感知**、**包装**、
**运行与诊断**。AI 面板提供口播切片、访谈精华、课程章节 3 个 `EditTemplate`
场景预设。

- **版本与片段**：revision 列表、base revision 对比、dry-run、渲染、产物；
  选中时间线片段时展示标签、源区间、置信度与选段依据。
- **我的偏好**：样本数/片段中位/保留率/top tags 与「按我的节奏规划」开关；
  开关切换 `preference_scope`（source/project），并排除被用户删除的标签。
- **字幕**：按输出时间线增删改 cue（开始/结束/文本），在播放头添加，
  重新载入字幕、清空、开关烧录；编辑立即更新预览，保存新版本后写入
  `EditIR.subtitles`。手动字幕优先于转写自动生成，空列表表示明确无字幕。
- **音频**：主输出音量增益（-30..+12 dB）与音调（-12..+12 半音）；
  音调通过 `asetrate + atempo` 保持时长。参数保存到 `EditIR.audio`。
- **多轨音轨**：音轨表支持添加/删除、原声/配音/BGM/stem、时间线起点、
  增益、静音、独奏、循环、淡入/淡出；`None` 表示旧单音轨行为，空列表表示静音。
- **音频 lane**：时间线在波形下方显示音轨块，支持多轨颜色、静音/独奏状态、
  循环铺满与素材波形。
- **混音预览**：音频修改后 600ms 防抖生成低码率混音预览；相同参数命中缓存，
  预览文件位于 `proxy/mix_*.mp4`，最终渲染仍只编码一次音频。
- **音频素材**：可导入 wav/mp3/m4a/aac/flac/ogg 为项目音频资产；
  资产按内容寻址并可在多轨中复用。
- **人声分离**：音频面板“分离人声/伴奏”调用外部 Demucs；
  结果注册为“人声/伴奏”素材，需手动加入音轨。未配置时提示安装方式。
- **大纲确认**：章节勾选/改名/排序、章节摘要/转写上下文、keyframe 预览、确认后 Phase B。
- **感知**：镜头/质量/人脸摘要、contact sheet、章节关键帧 seek；
  contact sheet 与关键帧异步加载并缓存。
- **证据**：可选 contact sheet / 帧差光流 / 光流条带 / bbox / ROI / codec 残差；
  面板显示证据缩略图与 `Txx` 时间码，点击行定位播放头；时间线只读叠加证据点、
  静音区与候选窗口。
- **语义证据**：屏幕文字 OCR、主体跟踪与相机/主体运动拆分目前注入章节 note /
  Planner，尚未在证据面板单独展示；OCR 开关/参数用 `SMARTCUT_OCR_*` 配置。
  批量渲染与 GpuMeasurer 对 GUI 透明，`measure_backend` 出现在运行 metrics/
  诊断信息中。
- **候选片段**：FTS 搜索、候选列表、多选后一键加入时间线。
- **运行指标**：wall/agent 耗时、队列等待、重试、cache H/M、命中率、
  LLM tokens、编码器；按 agent 展示。
- **运行记录**：run 列表、双击加载完整账本/metrics、缓存辅助续跑。
- **任务队列**：跨项目/当前项目任务列表，显示状态/进度/说明，可多选取消；
  有受监控任务时每秒自动刷新，无任务时停止轮询。`jobs.get`/`jobs.submit`/
  取消/续跑均在 QThreadPool 工作线程执行，UI 只处理快照与信号。
  活动/排队 Job 总数受 `SMARTCUT_MAX_PENDING_JOBS` 限制，满时状态栏提示错误。
- **诊断**：工作区/数据库/日志路径、policy 版本、硬件编码、视觉配置、
  活动任务与最近日志；可打开日志目录。

## 项目运维与窗口状态

- 项目面板支持重命名、删除、替换素材；删除前二次确认，
  后端会拒绝删除仍有排队/运行任务的项目。
- 删除持项目生命周期锁：删除期间新的 Job 提交/创建 run 直接失败；
  删除成功后项目进入 tombstone，等待锁的提交不会在删除后重建工作区。
- 切换项目、关闭窗口、退出前若时间线未保存，会询问保存/放弃/取消；
  选择保存后先提交 revision，再执行原动作。
- 窗口几何、停靠状态、主/中分割条尺寸、当前标签页、最近项目写入
  `desktop.json` 并在下次启动恢复；删除当前项目会清空最近项目。
- 主题支持深色/浅色/跟随系统（跟随系统当前按深色处理）、界面缩放、
  高对比度描边；English 语言选项禁用（未实现）。
- 界面采用统一深/浅色 QSS：面板圆角、强调色、表格/表头、滑杆、工具栏、
  标签页与状态栏一致；顶部工具栏使用 Qt 标准图标，不引入额外依赖。

## 通知与无头环境

- 后台任务完成/失败回调禁止调用 `QMessageBox.exec()`、`QMessageBox.question()`
  或 `QDialog.exec()`；统一使用状态栏、诊断面板或非模态 `show()/open()`。
- 恢复中断运行、审片结果、dry-run JSON 查看均为非模态提示；用户确认类
  操作通过按钮回调完成，不阻塞事件循环。
- `offscreen`/`minimal`/`SMARTCUT_HEADLESS=1` 下抑制所有确认/信息框并写日志；
  未保存提示按 `discard` 处理，避免 CI/无头测试永久挂起。
- `_on_error` 仍保持非模态错误框 + 诊断日志；退出时若有活动任务，
  仅在有图形界面时弹确认。

## Diff 可视化

- Inspector 选择两个不同 revision → “比较版本”。
- 文本列出 `+` 新增、`-` 删除、`=` 未变片段。
- 时间线：新增绿色、未变蓝色、删除红色底条。

## 字幕预览与设置

- 选中 revision 后加载字幕 cue；预览画面叠加当前字幕。
- 设置页支持字幕字号、颜色（#RRGGBB）、位置（上/中/下）；预览与烧录共用。
- 常用项只保留 DeepSeek/硬件编码/导出预设/字幕位置/主题等 8 项，
  其余感知、转写、视觉、Demucs、字幕样式等收进「显示高级设置」折叠区。
- 导出预设支持 mp4_h264、reels/douyin（1080x1920）、youtube（1920x1080）；
  导出对话框的平台预设会自动填充容器/编码/画幅/CRF。

## 特效与统一编辑

- “特效”标签页支持 fit/color/blur/sharpen/vignette/fade/zoom 的手动添加、
  参数编辑、预设、启用/禁用、排序与删除；与 Planner 共用同一 `EditIR.effects`。
- 作用域支持“全局”与“选中片段”：逐片段特效按稳定 `TrimOp.id` 绑定；
  时间线上带特效的片段显示 `FX` 徽标。删除片段后其特效会显示“片段已删除”，
  保存前必须删除或改绑。
- 时间线、特效、音频、字幕、导出共享统一编辑会话：任意修改进入同一撤销栈，
  `Ctrl+Z` / `Ctrl+Y` 撤销/重做整份草稿；保存时一次性生成新 revision。
- “预览特效”渲染 480p 全片代理（防抖、内容寻址缓存、可取消）；
  预览失败只提示状态，不阻断保存与最终渲染，最终渲染仍按原分辨率。
- 未保存提示覆盖时间线/特效/音频/字幕；快捷键在文本框、单元格与数值编辑中不拦截。
- AI 面板“锁定当前特效，AI 只改时间线”：把当前已启用的全局特效作为
  `pinned_effects` 提交；规划器只改 sequence/audio/export，锁定项与 AI 新时间线
  不兼容时整次运行明确失败，不静默丢弃。

## 转场 / 变速 / 水印

- “转场/变速/水印”标签页：逐片段速度、相邻片段转场（类型/时长）、
  文字/图片水印（位置、字号/缩放、颜色、透明度、时间窗口）。
- “导入图片/Logo”把图片复制进项目 `overlays/` 并登记为水印资产；
  IR 只引用 `asset_id`，不写路径。
- “去水印”按矩形区域填写 X/Y/宽/高 与时间窗口，渲染时用 `delogo`；
  编辑器自己添加的水印可直接删除/禁用。
- 这些字段写入 `EditIR.sequence[].speed`、`transitions`、`overlays`、`removals`，
  不进入 effects；保存时与特效/音频/字幕共用同一撤销栈与 revision。
- 转场/变速会改变成片时长，时间线仍按源区间展示，最终时长以渲染为准。
- AI 重规划生成的新 revision 默认不继承手动转场/变速/水印；这些属于当前手工时间线。

## 测试

```bash
python -m pytest -q tests/test_desktop_gui.py
python -m pytest -q tests/test_project_admin.py
python -m pytest -q tests/test_desktop_smoke.py
```

GUI 单元测试使用 minimal Qt 平台；完整窗口 offscreen 装配由 smoke 子进程覆盖。

桌面端不启动 HTTP 服务，任务进度一律通过 Qt 信号。
可选 FastAPI 服务端另提供 `GET /api/jobs/{id}/events` 与
`GET /api/runs/{id}/events`，以轮询数据库的 SSE 流返回状态；
WebSocket 尚未实现，桌面端也不消费 SSE。
